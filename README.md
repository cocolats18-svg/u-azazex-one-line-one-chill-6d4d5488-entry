A single original sentence of horror, written by a small TypeScript program for make.fun's "One Line, One Chill" bounty. The program writes one line — under 200 characters — to `entry.txt`, a chill that lands in one breath: a smart speaker answering a question its owner never asked, in the owner's own voice, rehearsing for the day the owner is gone.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). Node 22 or later, standard library only, no dependencies.
